# 1. Install the SlapFive Advanced Package

### **Salesforce Second-Generation Managed Packaging (2GP)**

SlapFive has migrated its Salesforce managed package from Salesforce's first-generation packaging architecture (1GP) to its newer second-generation managed packaging architecture (2GP). 2GP provides a modern, source-driven package development and versioning model and enables SlapFive to more efficiently develop, test, and deliver Salesforce App updates. [See comparison of 1GP and 2GP packages.](https://developer.salesforce.com/docs/platform/pkg2-dev/guide/sfdx-dev-dev2gp-comparison.html?utm_source=chatgpt.com)

### Install package for the first time

If this is the first time you are installing the SlapFive Advanced App, you will install the latest 2GP package.

{% hint style="info" %}
Click this link to install Version 4.25.0.4, select Install for All Users and click Install:

[https://login.salesforce.com/packaging/installPackage.apexp?p0=04tdL000000or7ZQAQ](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tdL000000or7ZQAQ)
{% endhint %}

### Upgrade a prior 1GP version to 2GP

If you are upgrading version 4.22 or earlier, you must first migrate from the 1GP to 2GP. This first requires you to upgrade to the baseline 1GP package:

{% hint style="info" %}
Click this link to install the baseline 1GP version 4.23.0.8, select Install for All Users, and click Upgrade:

[https://login.salesforce.com/packaging/installPackage.apexp?p0=04tgL000000SOH7QAO](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tgL000000SOH7QAO)
{% endhint %}

Then migrate baseline 1GP to 2GP:

{% hint style="info" %}
Click this link to migrate the baseline 1GP version 4.23.0.8 to 2GP version 4.23.0.1, and click Migrate:

[https://login.salesforce.com/packaging/installPackage.apexp?p0=04tdL000000oTRpQAM](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tdL000000oTRpQAM)
{% endhint %}

Then install the latest 2GP as described in next section.

### Upgrade a prior 2GP version to latest 2GP

Once you've migrated to the 2GP, you can upgrade from any 2GP to the latest 2GP here:

{% hint style="info" %}
Click this link to install Version 4.25.0.4, select Install for All Users and click Upgrade:

[https://login.salesforce.com/packaging/installPackage.apexp?p0=04tdL000000or7ZQAQ](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tdL000000or7ZQAQ)
{% endhint %}

### One-time CSP Trusted Site prompt

The install/upgrade page may show an “Approve Third-Party Access” dialog for https://sandbox.slapfive.com . Check the box and click **Continu**e — this is a mandatory Salesforce security gate for any package containing a CSP Trusted Site component, not something the\
package can suppress.&#x20;

Then add a Trusted Site for your own tenant’s domain:

Go to **Setup → Security → CSP Trusted Sites → New Trusted Site**, and add a Trusted Site for yourCompany.slapfive.com.
