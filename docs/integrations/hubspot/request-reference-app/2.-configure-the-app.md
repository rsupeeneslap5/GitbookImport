# 2. Configure the App

Go to **Connected apps** → **SlapFive Request Reference** → **Settings**.

Enter or paste into the following fields and click **Save**:

* [ ] **Button Text:** Enter the text you want to appear on the button. The default is _Request References_.
* [ ] **SlapFive form link:** Copy and paste the link to the SlapFive Request Reference form provided by your Customer Success Manager.
* [ ] **URL parameter name:** Leave this set to id unless told otherwise by your SlapFive Customer Success Manager.
