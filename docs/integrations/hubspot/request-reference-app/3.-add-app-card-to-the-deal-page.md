# 3. Add App Card to the Deal Page

You can put the Request Reference App's Card anywhere on the Deal page that allows custom Cards. Typically it is placed in the right column.

Open a Deal and click the Customize link. Do the following and click **Save** or **Save and Exit**:

* [ ] Click the view you want to edit. That's usually the **Default view**, but it could also be a team-specific view if you use those.
* [ ] Choose where the card should go. For the middle column, pick a tab like Overview and click **+ Add cards**. For the right sidebar, click **+ Add cards** in the sidebar section.
* [ ] Click the **Card Library** tab and search on _SlapFive_.
* [ ] Click the Add Card button.

You will now see the Card in the location you chose.
