# Connect to Monday.com

To protect the security and privacy of your Monday.com data, SlapFive's Embedded Integration eliminates the need for you to email or message us with your authentication credentials. You can simply connect right from within SlapFive. You only have to do this once and it will be used for all automations. The login data is encrypted and stored within the Embedded Integration.

1\. In SlapFive, go to the Admin menu, click **Settings**, and click on the **Integrations** sub-tab.

2\. Click the **Monday.com Connection** box to expand it. Enter the following fields and click **Connect**.

* [ ] **API v2 Token:** Paste your Monday.com API Token. To get your API Token, go to Administration > API > Generate API v2 token. For Monday.com's documentation page, [click here](https://developer.monday.com/api-reference/docs/authentication).

Once you are successfully connected, the button should now say **Disconnect**, and you should see a green <mark style="color:green;">**Connection success**</mark> message.
