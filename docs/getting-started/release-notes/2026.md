# 2026

### August 2026

* Referrals:
  * There is now a dedicated Referrals object and menu option for tracking the progress of submitted customer referrals. Previously, Referrals were tracked using a Campaign.
  * Both the Referrer and the Referral are tracked as Members and Companies. There is a new Member Type value for Referral so you don't include Referrals in your Advocate count.
  * Submitted Referrals automatically create Revenue Influence records.
* Surveys Enhancements:
  * There is a new Survey response style called Chat, which mimics the AI bot experience for survey responders.
  * You can define Custom Action Rules to trigger automate action for Survey and Prompt response events. Common use cases:
    * Have a Prompt response update the Member's Activity Types Willing to Do, Avatar, or any standard or dynamic field.
    * Have a Survey response notify another team if a response contains a certain value.
* Dynamic Fields:
  * You can now add Dynamic Fields to the native SlapFive Opportunity object. These can be used to capture custom Salesforce Opportunity and Account fields within SlapFive.
* User Experience Enhancements:
  * On the Member and Company Profile pages, you can configure which columns appear in each list of related objects, such as Activity History and Campaigns.
  * You can now hide standard Fulfillment Member fields of you don't have a need to override the Request Need By Date, Activity Type, and Assigned To fields at the Fulfillment Member level.
  * On the Stories tab, in Card view, you can click anywhere in the card to preview that Story.
  * For a PICK ONE or PICK MANY dynamic field, you can sort the picklist values with one button click.
* API:
  * There is a new API endpoint to POST Assets.
  * There is a new Webhook and GET, GET by ID, and POST endpoints for Referrals.

### July 2026

* Answer Engine Optimization (AEO): SlapFive has added many features to help ensure that customer content stored in SlapFive is put to work to help ensure that your company and products are included in the conversations that your potential buyers have with answer engines like ChatGPT, Claude, Gemini, and Perplexity.
  * SlapFive generates distinct pages for each Story, using your subdomain, that expose customer content in question/answer pairs, which is highly sought by AEO bots
  * SlapFive generates a sitemap for these pages that ensure the AEO bots are trained on this content.
* Surveys Enhancements:
  * There is now a Finish Later button on the Open Survey response screen. If the responder clicks that button, SlapFive sends an email to the email address they entered on the first screen with a link they can use to respond at a later date.
  * If the responder just closes the browser tab part way through, there is a new setting on the Survey for what to do the next time they click the Open Survey link and enter the same email address on the first screen:\
    – SlapFive detects that there is an in-progress response for that email address and presents the responder with this screen where they choose whether to continue with the one in progress or start a new response.\
    – Always take them to where they left off\
    – Always start a new response
  * Responders can back up to earlier Prompts in the Survey, change their responses and SlapFive keeps an audit trail of all the responses.
  * For any Prompt, you can uncheck the Create Story From Response field to avoid creating Stories. In your case, I suggest we uncheck this field as we don’t need to create Stories to generate the Board, we strictly use the Response data.
  * The user interface for adding Prompts to a Survey now allows you to search and filter on Prompts to find the ones to add.
* SSO Enhancements:
  * You can require that the SSO IdP provide a Role/Group.
  * You can define a default Role to assign a User when the SSO IdP doesn’t pass a Role/Group. This is useful when you are using SSO to protect Boards for use cases like Sales Win Wires, and you don’t want to explicitely add every user to the SlapFive App.

### June 2026

* AI and MCP Server:
  * Claude Cowork Connector: You can now connect to SlapFive’s MCP Server from Claude Cowork, and access a set of Skills within Cowork.
  * Microsoft Copilot Connector: You can now connect to SlapFive’s MCP Server from Microsof Copilot.
* Clone an Instance:
  * This allows you to create a Sandbox instance of SlapFive for testing.
* Advanced Filters Enhancements:
  * Members list: Filter on Salesforce Contact ID and Salesforce Account ID
  * Companies list: filter on Salesforce Account ID
  * Requests list: filter on Opportunity ID
  * Fulfillment Members list: Filter on Salesforce Contact ID, Salesforce Account Id, and Opportunity Id
  * All lists that show Activity Types: See the Activity parent/child hierarchy in the Filter dropdown
* Requests Enhancements on the Fulfill Request Screen:
  * There is an option to hide the Save and Respond button.
  * In the list of Fulfillment Companies & Members, you can hide the Need By Date, Activity Type, and/or Assigned To columns.

### May 2026

* Surveys: SlapFive has turned Prompt Groups into a robust Surveys feature:
  * There are two new Presentation Styles for Surveys in addition to the Standard: 1) Conversational, which is a chat-style interface where questions appear as bot bubbles and answers as replies, similar to ChatGPT or Claude interface, 2) Wizard, which animates slide-cards with a progress bar and step counter.
  * You can now have Prompt responses that update Member or Company profile fields, add Member Activity Types Willing to Do, and trigger automated workflows.
  * You can do NPS Surveys by having an NPS Score  question that is Numeric response with a horizontal buttons from 0-10, and then condition the next question based on the response to the NPS Score question.
  * You can launch Surveys from SlapFive Embeds that are embedded in any other app.
  * You can set the order of the Allowed Response Type when multiple options are provided.
  * You can add Select One and Select Many multiple choice questions, show the options in an expanded list or dropdown, and set the minimum and maximum number of choices allowed for Select Many.
  * You can turn off the creation of Stories for a Prompt for cases where you’re not capturing customer voice.
  * You can set each Prompt as Required or show a “Skip this Question” option on the response screen.
  * You can set Action Rules to do things like skip to a particular question based on the answer to a previous question and send response notifications.
  * There are new webhooks and API endpoints for Completed Surveys and Getting Survey Responses that enable unlimited automation scenarios.
* Embeds Enhancements:
  * You can embed Advocate Profiles within your customer community platform. The Advocate Profile shows the Advocates Engagement Score, Available Points, place in your tier structure, personalized Advocacy Opportunities, completed Activities, and the ability to update Activity Types Willing to Do.
  * You can embed Surveys in your own apps.

### April 2026

* Revenue Influence Modeling and Reporting: SlapFive has added native Revenue Influence Reporting so that you can track and measure Revenue Influence right within SlapFive. This extends Revenue Influence Reporting to clients that use HubSpot or other CRMs besides Salesforce, and provides more Revenue Infuence Events.
  * You can define the Revenue Influence Scoring Model by defining Influence Scores to each Influence Event.
  * You can generate Revenue Influence records for all Requests and Content Shares/Views that are associated with Opportunities.
  * There is a new dashboard with many out of the box Revenue Influence charts and graphs.
* Sales Opportunities: To enable Revenue Influence Reporting and to provide more visibility into Sale Opportunities while fulfilling reference requests, SlapFive has added an Opportunities object.
  * The Opportunities object stores Name, Description, URL, Stage, Amount, Created Date, Close Date, Is Closed?, Is Won?, CRM, Type, Lead Source, and Account ID.
  * There is a calculated Length of Sales Cycle field that calculates the number of days between the Created Date and Close Date.
  * There is a new menu tab for viewing all Opportunities.
  * On the Fulfill Request screen, you can click a new Opportunity icon to open a tray to see all the Opportunity fields.
  * You can refresh Opportunities from the CRM at any time to get updated fields like Stage and Amount.
* Analytics & Reporting Enhancements:
  * A drill-down feature has been added to lists and charts so you can, for example, click a customer name to go to their Member screen or click a pie chart slice to see the records that comprise that slice.
* Security:
  * SlapFive engaged an outside party to conduct the annual Penetration Test and resolved all findings.

### March 2026

* Embeds: SlapFive has introduced a major new module called Embeds.
  * Embeds allow you to render SlapFive data and features on stand-alone pages and embedded as widgets within other apps.
  * Here are some examples of use cases for Embeds:
    * Within your customer community, show the Advocate Profile page for that community user.
    * Offer opportunities to perform acts of advocacy in any other system.
    * Create “board of boards” for Win-Wires so you can embed a catalog of Win-Wires within Salesforce
* Edit Boards:
  * When adding and removing Stories from a Board, there is now a Search and Advanced Filter for finding the right Stories.
* API:
  * All POST endpoints now populate the new DATE/TIME dynamic fields.
  * The GET Board by Id endpoint now returns the dynamic fields for each Story on that Board.
  * The POST Companies endpoint now let’s you change the Company Name when you provide the record id and the new name in the BODY.
  * The POST Companies endpoint let’s you change the Salesforce Account ID when you provide the record id and new salesforceAccountId in the BODY.
  * The POST Customers (Members) endpoint let’s you change the Member’s email address when you provide the record id and the new email in the BODY.

### February 2026

* Configure List Columns:
  * For any list, users can now change the columns that appear in that list, and the sequence in which the selected columns appear.
  * The available columns include all standard and dynamic fields for the immediate object, as well as any parent object. Example: The Members list can include Member and Company standard or dynamic fields.
  * To make it easier to recognize what row data represents, the column header row now freezes in place when you scroll down the list.
* Dynamic Fields:
  * You can now create dynamic fields of type DATE/TIME for any object. This is used in the Reference Automation workflows to store the customer’s available dates/times and the prospect’s selected date/time.
* Requests and Request Fulfillment Companies/Members Lists:
  * The Requests list now has an option to toggle to List View in addition to the Kanban View.
  * The Fulfillment Companies/Members list now has an option to toggle to Kanban View in addition to the List View.
  * The Fulfillment Companies/Members list now has an advanced filter.
  * You can export the Fulfillment Companies/Members list.
* User Experience Enhancements:
  * After selecting Advanced Filter criteria, you can now click a single button at the top of the tray to clear all advanced filter criteria.
  * Deleting Activity Types gives you warnings of where that Activity Type is used.
  * URLs in long text fields are clickable to launch the linked page.

### January 2026

* Merge Members and Companies:
  * You can now merge duplicate Member and Company records.
  * You select which Member or Company to keep, and the other Member or Company go away after the merge.
  * For each field, you can then override the field value to keep if necessary.
* Bulk Add Activity Records:
  * From the Members list, you can select multiple Members and click the Add Activity button to add a new Activity record for each selected Member.
  * To facilitate this, you can do a search or use the advanced filter to subset the Member list first.
* User Management:
  * You can now make a User inactive. This is useful when a colleague leaves your company and you want to prevent them from logging in, but you don’t want to delete their User record since it is used in historical records.
  * If you have set up Single Sign-On, you can now disable direct username/password logins to prevent users from circumventing SSO.
* Story Text Spelling and Grammar Checker:
  * You can now check the Story Text field for spelling and grammar errors and correct them.
  * This is useful for story text generated from AI Agents, for example the Gong listener.
* Require Activity Type on new Requests: You can now set it so that Activity Type is a required field on new Requests.
* Boards and Templates:
  * Templates now have a tab for Script that allows the inclusion of javascript code when the Board is rendered. This enables use cases such as using Boards for custom forms.
  * When editing a Board, in addition to adding Stories, you can now add Prompts and Members. Adding Prompts to a Board is useful for Boards or widgets that contain advocacy opportunities to embed in your community. Adding Members to a Board is useful for creating Leaderboards or CAB Membership Boards.
  * On the Edit Board screen, Stories tab, you can click a new Edit button one each selected Story to launch the Edit Story screen and make edits on the fly.
* User Experience Enhancements:
  * After selecting Advanced Filter criteria, you can now click a single button at the top of the tray to clear all advanced filter criteria.
  * Deleting Activity Types gives you warnings of where that Activity Type is used.
  * URLs in long text fields are clickable to launch the linked page.
* Prompt and Prompt Group response screens now use your Custom Domain if you have it set up in Client Settings.
* API Endpoints and Automations:
  * The POST Boards endpoint allows you to upload the Board Image and CTA Image, and to pass a set of Story IDs to add Stories to the Board.
  * The POST Customers (Members) endpoint allows you to change the Company that the Member is associated with by passing a different companyName.
  * The POST Customers (Members) endpoint allows you to pass Limits when assigning Activity Types Willing to Do.
  * The POST, GET, and Webhook for Fulfillment Companies/Members now handle Fulfillment Company/Member dynamic fields.
  * The Boards Webhook now returns tagline, useAtStages, customURL, boardImage, ctaImage, ctaHead, ctaCopy, ctaLink, ctaLinkText.
  * There is a new POST Campaigns endpoint for searching for Campaign Items within a Campaign based on multiple column values.
  * There is a new Prompt Response Webhook that fires whenever a customer responds to a Prompt. This can be used for many automation use cases, such as notifications.
  * There are new GET endpoints to get all Templates, get Template by ID, and get Template by Name.
  * There is a new POST Activity Types endpoint for bulk uploading new Activity Types.
  * There is a new POST Dynamic Fields endpoint for bulk uploading new picklist values for PICKONE and PICKMANY dynamic fields.
* System Administration: SlapFive System Admins can clone an instance. This can be used to create a sandbox instance with data from your production instance.
