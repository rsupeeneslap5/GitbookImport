# Reference Submission Workflow – Testing Preparation

Before testing begins, please make sure the following items are set up:

1\. Create a Test Customer Account in Salesforce (Client SFDC Team)

Create a test account that includes:

* Industry
* Product/Segment
* Location
* Account Owner (ideally the Customer Marketer or someone participating in training)

Also create a test Opportunity associated with this account.

#### 2. Set Up a Test Customer in SlapFive (Customer marketing team or S5 to create)

Create a company in SlapFive that will serve as your test reference customer.

Within that company:

* Create a member (Customer Marketer or designated tester).
* Ensure the member is:\
  <br>
* Active
* Assigned the Member role

#### 3. Add the Nomination Contact

On the Salesforce test account:

* Add the Customer Marketer (or designated tester) as contact&#x20;

#### During testing:

* You will nominate yourself as the customer contact.
* The person being nominated must not already exist as a member in SlapFive. If they already exist, create a new test contact instead.
