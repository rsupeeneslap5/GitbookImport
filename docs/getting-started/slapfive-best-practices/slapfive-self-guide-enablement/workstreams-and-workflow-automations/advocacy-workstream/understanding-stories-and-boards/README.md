# Understanding Stories and Boards

&#x20;Boards are curated collections of Stories created for specific audiences.\
\
**Examples of Board Usage**\
• Sales enablement\
• Executive presentations\
• Industry-specific proof points\
• Product-focused references\
• Event preparation\
\
**Benefits of Stories and Boards**\
• Faster content discovery\
• Better sales adoption\
• Stronger storytelling consistency\
• Easier executive access\
• Improved customer proof organization\
\
**Best Practices**\
• Keep Stories concise\
• Include measurable outcomes\
• Organize Boards strategically\
• Update outdated content regularly\
• Tag Stories consistently
