# Data Migration and Ongoing Sync Management

**Before Migration**\
Prepare:\
• Member records\
• Company records\
• Required fields\
• Duplicate cleanup\
• Naming standards\
\
**Common Data Sources**\
• Salesforce\
• Forms\
• Customer communities\
• Customer success platforms\
• Spreadsheets\
\
**One-Time Imports vs Ongoing Syncs**\
Some organizations import data once, while others maintain automated integrations.\
\
**Best Practices**\
• Define a source of truth\
• Align field mappings carefully\
• Audit sync quality regularly\
• Validate imported data before launch\
• Maintain governance ownership
