# Understanding Membership Profiles

\
\
**Profiles power:**\
• Search and filtering\
• Advocate segmentation\
• Request matching\
• Campaign targeting\
• Reporting and analytics\
\
**Core Fields vs Dynamic Fields**\
**Core fields are standardized fields used across the platform, such as:**\
• Name\
• Company\
• Role\
• Email\
• Geography\
\
**Why Data Quality Matters**\
**Strong profile data improves:**\
• Faster reference matching\
• Better segmentation\
• More accurate reporting\
• Improved sales adoption\
• Stronger campaign targeting\
\
**Best Practices**\
• Standardize naming conventions\
• Avoid duplicate fields\
• Keep profile data updated regularly\
• Use consistent dropdown values\
• Remove outdated or inactive records\
\
**Filtering Logic**\
SlapFive supports layered filtering to help teams quickly identify the right advocates.Understanding filtering logic helps your team search faster and improve request fulfillment speed.\
\
Examples:\
• Find healthcare customers using Product X\
• Find advocates willing to speak at events\
• Find enterprise references in Europe\
