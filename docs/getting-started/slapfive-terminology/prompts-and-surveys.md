# Prompts & Surveys

### Prompts

Questions or statements used to invite engagement or collect specific responses from Members.

Prompts can accept responses in multiple formats, including video, audio, text, numeric input, files, or links.

### &#x20;Direct Prompts (Remote Capture)

Prompts sent directly to specific named Members.

Recipients receive an email and/or text message with a link that allows them to respond using the permitted media types.

### &#x20;Open Prompts (Remote Capture)

Shareable prompt links that can be distributed anywhere.

Anyone with the link can respond. Respondents are asked to provide their name, company, and email address. Open Prompts can be used with both existing Members and non-members.
